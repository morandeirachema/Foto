## 📌 Datos del móvil que conviene saber

De las especificaciones de Google:

| | |
|---|---|
| 🔭 **Zoom óptico hasta 5x** | Google da «calidad óptica» en 0,5, 1, 2, 5 y 10 aumentos |
| 🤖 **Más de 30 aumentos es IA generativa** | El móvil guarda también la versión sin IA: quédate con esa |
| 🌌 **Astrofotografía solo desde 1x** | A 0,5x el modo no aparece |
| 📶 **El Asistente de cámara necesita Internet** | Sin cobertura no funciona |
| 💧 **IP68** | Aguanta lluvia y polvo que la a6700 no debería ver |
